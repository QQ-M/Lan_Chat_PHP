# 局域网聊天程序

这是一个使用PHP编写的简单局域网聊天程序，旨在提供一种在局域网内轻松交流的方式。

## 功能特性

- **即时通讯**：可以在局域网内的设备之间发送和接收消息。
- **多用户支持**：允许多个用户同时在线聊天。
- **文件传输**：支持发送文件和图片，图片支持预览和大图查看。
- **图片粘贴**：支持直接粘贴剪贴板中的图片进行发送。
- **自动链接检测**：文本消息中的URL会自动转换为可点击的超链接。
- **内网免登录**：局域网内设备自动识别并创建用户，无需手动注册登录。
- **消息记录**：聊天记录会自动保存，方便用户查看历史消息。
- **简单易用**：界面直观，操作简便。

## 安装与运行

### 先决条件

- PHP 7.4+
- MySQL 5.7+
- Web服务器（Apache/Nginx）

### 安装步骤

1. **克隆仓库**：
   ```bash
   git clone https://github.com/QQ-M/Lan_Chat_PHP.git
   ```

2. **配置数据库**：
   - 创建MySQL数据库
   - 导入 `Create_SQL.sql` 创建表结构
   - 修改 `db.php` 中的数据库连接信息

3. **配置Web服务器**：
   - 将项目目录设置为Web根目录
   - 确保PHP有写入 `uploads/` 目录的权限

4. **访问应用**：
   ```
   http://your-server-ip/
   ```

## 功能说明

### 内网免登录
- 局域网内设备首次访问时自动创建用户（基于设备名或User-Agent）
- 后续访问自动登录，无需输入用户名密码
- 外网访问需要手动注册登录

### 文件上传
- 支持发送任意类型文件
- 图片文件支持缩略图预览
- 点击图片可查看大图
- 支持直接粘贴剪贴板图片

### 自动链接检测
- 自动识别文本中的HTTP/HTTPS/FTP链接
- 自动识别www.开头的链接
- 链接在新标签页中打开
- 针对自己和他人的消息使用不同链接颜色

## 技术栈

- **后端**：PHP + MySQL
- **前端**：HTML + Tailwind CSS + JavaScript
- **图标**：Font Awesome
